# Changelog

All notable changes to this project are documented here.

## Unreleased

- Added: **Translation review** on/off per shop language (*Modules → Module Manager → Supertext Translation → Configure → Languages*, column *Translation review*): translations into a language with it ticked go through Supertext's review service (Supertext Localization Review), where customers and Supertext linguists correct them on the shop's website with a Chrome extension; corrections come back into PrestaShop with the next translation (with *Overwrite existing translations*), and texts translated before keep their (reviewed) wording. Same API key, billing, languages and messages; other languages keep going directly to Supertext. New setting *Review service URL* (defaults to Supertext's review service; empty turns review off for every language; `SUPERTEXT_REVIEW_URL` on the server wins). Languages saved before have review off. All new texts in English, German, French and Italian.
- Changed: requests to Supertext name the module's version in the User-Agent (`PrestaShop-Supertext-Translation/<version>`).
- Added: **Export for translation (XLIFF 1.2 or HTML) and import of translated files**; Supertext SDK 0.5.0. On the *Translate with Supertext* page, *Export for translation* downloads an item's fields as an XLIFF file (one or more languages, for translation tools) or an HTML file (one language, e.g. for Supertext's web app); *Import translation* reads the translated file back into the item's language fields with the same rules as API translations (existing translations kept unless *Overwrite existing translations*; texts whose source changed since the export only with *Also import texts whose source changed since the export*) and shows a summary per item and language. Same permission as translating, files up to 10 MB, nothing stored on the server. All new texts in English, German, French and Italian.
- Changed: **default Supertext languages where they are obvious** (Supertext SDK 0.4.0). In *Configure → Languages*, each shop language's *Supertext language* list now preselects a suggestion: the same code (`de-CH`, `es`), else the usual one (`de` → `de-DE`, `en` → `en-US`, `es-ES` → `es`, `zh-CN` → `zh-Hans`, `zh-TW` → `zh-Hant`). A language nobody chose a Supertext language for is translated with that suggestion instead of being refused; only languages without one (`en-IE`, `de-LI`, `gsw`) show *— choose —* and the hint *No suggestion for this language*. The list shows the languages' names in the back-office language. The tone is only offered where Supertext has formal/informal for the chosen language, and a tone saved for one without it isn't sent. Saving accepts only codes from the list. Codes saved by 0.1.0's free-text field are converted to codes of the list (`de-ch` → `de-CH`, `de` → `de-DE`, `es-ES` → `es`); unknown ones are kept. The *has no Supertext language* message now says where to choose it. All new texts in English, German, French and Italian.
- Changed: version reports, the API key check result and the reachability ping now use Supertext Plugin Health 0.1.0 (bundled in `supertext/lib/supertext-plugin-health/`); Supertext SDK updated to 0.3.0. No change for shops: settings and stored state stay as they are.
- Changed: **languages are no longer guessed.** The *Languages* panel now has a **Supertext language** list (Supertext's own codes) per shop language instead of a free-text code. A locale that is a Supertext code (`de-CH`, `fr-CH`, `es`, apart from case and `_`/`-`) is preselected; every other locale (`de`, `es-ES`, `zh-CN`) needs a choice. The default regions are gone: they were wrong for most languages (Supertext wants `es`, `sl`, `nl` without region, `zh-Hans` instead of `zh-CN`). A language without a Supertext language is marked *Not mapped*, can't be ticked on the translate page and gets the message *has no Supertext language yet*; nothing is sent for it. Codes saved before keep working. The panel warns when a formal or informal tone is set for a language Supertext offers none for, with its own message *Supertext offers no formal or informal tone for this language*. All new texts in English, German, French and Italian.
- Added: automatic **API key check** (Supertext's cost-free `features` call) when the settings are saved, on *Test connection*, for a key that hasn't been checked yet and when Supertext rejects the key during a translation. The settings page shows the latest result with its time; *Test connection* shows the same messages.
- Added: **Send version information to Supertext** (on by default; `SUPERTEXT_VERSION_REPORTS=0` turns it off): when the settings are saved and after an update, the module sends the shop URL, the module, PrestaShop, PHP and SDK versions, whether a key is set, the key check result and the ping address to Supertext. No content, no API key and no personal data.
- Added: public ping endpoint `index.php?fc=module&module=supertext&controller=ping`, which only echoes Supertext's challenge so Supertext can check that the shop is reachable (404 with version information off).
- Changed: bundled Supertext SDK 0.2.1 (commit `eeba8fa`, `V1` namespace) with the language list, the key check and the version reports.
- Changed: the *no API key* and *authentication failed* messages also link to the Supertext account page.
- Changed: all Supertext API calls now go through the official Supertext PHP SDK, shipped inside the module (nothing extra to install). The module now needs PHP's curl extension, which PrestaShop requires anyway.
- Added: its own message for an unsupported language pair, naming the codes ("Supertext does not support this language pair (en → xx-YY)"), in English, German, French and Italian.
- Fixed: the source language is taken from the locale instead of PrestaShop's ISO code, which is country-like for some languages (`gb` for English (UK)).
- Added: French and Italian interface (and German, which was missing). The module's screens and messages, including errors from Supertext, follow the employee's back-office language (translations shipped for de-DE, de-AT, de-CH, fr-FR, fr-BE, fr-CA, fr-CH, it-IT, it-CH).
- Demo: the public host name comes from `PRESTASHOP_DOMAIN` (or Railway's domain) instead of `PS_DOMAIN`, which the base image sets to a placeholder; the demo now runs on Railway.

## 0.1.0 — 2026-10-08

- First version: PrestaShop module `supertext` (PrestaShop 9.x tested, 8.1+ supported; PHP 8.1+).
- **Translate with Supertext** as a bulk action and a row action in *Catalog → Products*, *Catalog → Categories* and *Design → Pages*, and as a button in the product page's *Modules* tab.
- Translate page: source language, target languages, the current translation state per item and language, and an explicit *Overwrite existing translations* option with a warning. Translations run one item and language at a time, with the result shown per cell.
- Translates product name, summary, description, meta title and description, availability labels and delivery times; category name, description, additional description, meta title and description; CMS page title, meta title, meta description and content. Rich text keeps its formatting; friendly URLs follow the translated title while untranslated.
- Fills only fields that are empty or still a copy of the source language, unless *Overwrite* is ticked.
- Settings: API key (with or without the `Supertext-Auth-Key` prefix; `SUPERTEXT_API_KEY` wins), links to create a Supertext account and generate the key, *Test connection*, API environment, custom endpoint (`SUPERTEXT_API_ENDPOINT` wins), timeout, per-language Supertext code and tone, module version linked to its release.
- Requests that hit Supertext's per-second rate limit are retried automatically.
- CLI: `php bin/console supertext:translate <product|category|cms> <ids> [--to=<iso>] [--from=<iso>] [--overwrite]`.
- Demo for Railway (`demo/`): PrestaShop 9 on MySQL with German (CH), French (CH) and Italian (CH), sample products, category and CMS page, and `DEMO_ADMIN_*` / `DEMO_EDITOR_*` accounts created on every start.
- Docs with screenshots, regenerated by `tests/docs/screenshots.mjs` against a stand-in API.
